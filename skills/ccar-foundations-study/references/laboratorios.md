# Exercícios sugeridos para CCAR-F

**Atenção:** são exercícios pedagógicos gerados para esta skill, não exigências adicionais confirmadas pelo guia oficial. Usar apenas o escopo e domínios de `escopo-base.md`.

### Orquestração

Desenhar agente coordenador e dois especialistas com escopos explícitos, falhas esperadas e passagem de contexto.

### Controles determinísticos

Decidir se uma regra deve ser assegurada por hook, permissão, validação de código ou instrução textual.

### MCP e ferramentas

Revisar uma coleção de tools e identificar descrições ambíguas, excesso de privilégio e tratamento de erros.

### Confiabilidade

Projetar compactação, rastreabilidade de fontes e recuperação de falhas num workflow multiagente.

## Como avaliar

Para cada atividade: estabelecer critério de aceite simples, pedir primeiro a decisão do estudante, apontar trade-off omitido, propor correção e registrar tópico que precisa de revisão.
