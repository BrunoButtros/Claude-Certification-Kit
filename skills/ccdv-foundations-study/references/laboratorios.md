# Exercícios sugeridos para CCDV-F

**Atenção:** são exercícios pedagógicos gerados para esta skill, não exigências adicionais confirmadas pelo guia oficial. Usar apenas o escopo e domínios de `escopo-base.md`.

### Messages API

Raciocinar sobre roles, system, stop_reason e fluxo de retorno; usar payload fictício sem credenciais reais.

### Confiabilidade

Projetar tratamento de 429/529, backoff e idempotência para uma chamada de API sob falhas.

### Tools e MCP

Definir um JSON Schema mínimo para ferramenta e planejar tratamento de tool_result e is_error.

### Evals e segurança

Criar cinco casos de avaliação e um teste de prompt injection para uma integração simulada.

## Como avaliar

Para cada atividade: estabelecer critério de aceite simples, pedir primeiro a decisão do estudante, apontar trade-off omitido, propor correção e registrar tópico que precisa de revisão.
