# Claude Certified Developer – Foundations (CCDV-F)

Esta certificação integra o programa da Anthropic para organizações parceiras. Confirme elegibilidade e acesso na [FAQ oficial](https://anthropic-partners.skilljar.com/page/faq-certifications); estudar com esta skill não exige informar empresa ou e-mail.

## Conteúdo desta preparação

Base de conteúdo: 10/11/2026. Os domínios e pesos abaixo são os da baseline, ainda não integralmente conferida com o guia oficial autenticado.

| Domínio | Peso | Assuntos |
|---|---:|---|
| Applications & Integration | 33.1% | Messages API (roles, system, max_tokens, stop_reason), streaming, tratamento de erros e retries (429, 529), prompt caching (cache_control, tempo de vida do cache), Message Batches API, structured outputs, extended thinking, SDKs, Files API, desenho de aplicação por interface |
| Model Selection & Optimization | 16.8% | Opus x Sonnet x Haiku por qualidade, latência e custo; janela de contexto; redução de custo e latência com caching, batches e roteamento entre modelos |
| Agents & Workflows | 14.7% | Agentic loop guiado por stop_reason; padrões de workflow (prompt chaining, routing, parallelization, orchestrator-workers, evaluator-optimizer); quando usar workflow x agente; subagentes; Claude Agent SDK |
| Prompt & Context Engineering | 11% | System prompt, tags XML, few-shot, raciocínio passo a passo, posicionamento em contexto longo, gestão e compactação de contexto |
| Tools & MCPs | 10.6% | Definição de ferramenta com JSON Schema, descrições, tool_choice, chamadas paralelas, tool_result com is_error; Model Context Protocol (MCP): tools, resources, prompts e transportes |
| Security & Safety | 8.1% | Injeção de prompt (prompt injection), menor privilégio, dados pessoais, guardrails, aprovação humana para ações de risco |
| Claude Code | 3.1% | CLAUDE.md, permissões, slash commands, hooks, modo não interativo (-p) em CI |
| Evaluation, Testing & Debugging | 2.6% | Conjuntos de avaliação, LLM como juiz (LLM-as-judge), testes de regressão de prompt, depuração de respostas |
