# Exercícios sugeridos para CCAO-F

**Atenção:** são exercícios pedagógicos gerados para esta skill, não exigências adicionais confirmadas pelo guia oficial. Usar apenas o escopo e domínios de `escopo-base.md`.

### Avaliação de saída

Comparar duas respostas sobre uma política fictícia; classificar precisão, completude, viés e necessidades de revisão humana.

### Seleção de produto

Escolher entre Chat, Projects, Research e Artifacts para três tarefas de trabalho com restrições de contexto.

### Governança

Reescrever um fluxo de negócio para remover dados pessoais desnecessários e acrescentar pontos de aprovação humana.

### Troubleshooting

Diagnosticar uma resposta insatisfatória distinguindo prompt vago, contexto ausente e fonte inadequada.

## Como avaliar

Para cada atividade: estabelecer critério de aceite simples, pedir primeiro a decisão do estudante, apontar trade-off omitido, propor correção e registrar tópico que precisa de revisão.
